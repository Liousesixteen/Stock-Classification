# 数据源商用授权与展示边界

本文件是上线门禁，不是对数据授权状态的法律结论。所有标记为“待书面确认”的来源，在获得供应商或权利人书面许可前，只能用于内部研发验证，不得作为面向客户的商业数据服务。

| 数据源 | 当前用途 | 商用状态 | 上线前展示边界 |
|---|---|---|---|
| 东方财富 Push2 / F10 / 研报入口 | 行情摘要、公司资料、主营与研报线索 | 待书面确认 | 不批量再分发，不展示完整研报正文，保留来源链接和采集时间 |
| 腾讯行情 | 基础报价与名称补全 | 待书面确认 | 仅展示必要摘要，不提供镜像下载或历史批量导出 |
| 百度相关板块 | 行业与概念线索 | 待书面确认 | 标记为线索，不把自动关联表述为官方分类 |
| 巨潮资讯公告 | 上市公司公告检索与证据 | 待确认网站条款及接口许可 | 展示标题、日期、短摘录和原文链接，不替代法定披露页面 |
| 新浪财务报表 | 三大财务报表字段 | 待书面确认 | 展示计算所需字段和来源，不复制完整数据产品 |
| DeepSeek API | 分类、研究和研报生成 | 依账户合同与模型条款 | 不提交密钥、个人敏感信息或无授权全文；保留模型与生成时间 |
| 用户本地导入 | 公司、关系和证据 | 由用户保证权利 | 导入前提示权利责任，导出仅限当前授权范围 |

## 上线门禁

每个数据源必须补齐：

- 权利人/供应商名称与合同编号；
- 允许的用途：内部分析、对客展示、缓存、派生指标、导出；
- 并发、频率、缓存期限和删除义务；
- 原文链接、品牌署名和免责声明要求；
- 个人信息、跨境和日志保留要求；
- 到期日、续约负责人和紧急下线开关。

任何来源授权不清时，Provider 应被关闭或返回“待补/同步失败”，不得用 AI 猜测替代。面向客户的页面应只展示已授权字段、必要摘要和可追溯来源。

## 当前结论

技术上的超时、缓存、重试和熔断不等于获得数据授权。现有公开网页 Provider 在法务/采购完成书面确认前，不能据此宣称可商用；这项确认是生产发布的外部阻塞项。

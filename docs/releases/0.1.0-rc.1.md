# 0.1.0-rc.1 发布候选说明

发布日期：2026-07-27

## 版本目标

本候选版本把系统收敛为四个互相衔接的工作区：研究工作台、产业链图谱、成果库和任务中心，并打通“发现标的 → 核验档案 → AI 研究 → 生成研报 → 沉淀成果 → 后续任务”的核心闭环。

## 主要能力

- 统一公司数据 Provider、字段级来源、采集时间、可信度、验证状态、缓存、超时、重试、降级与熔断。
- 持久化资料同步队列，支持排队、执行、部分完成、完成、失败、租约恢复、幂等和手动重试。
- 结构化公司研究档案，覆盖业务、产业链位置、优势、客户、财务、催化、风险、证据时间线和真实完整度评分。
- 数据驱动的产业链图谱，支持分类、公司、证据和跨链关系，以及搜索、悬浮快照、路径追踪和上下游筛选。
- 通用 AI 研究与多 Agent 联合研判，所有事实结论必须绑定本地工具取得的证据。
- 公司、赛道、对比和事件四类研报，支持版本历史、AI 改写、质量检查以及 Markdown、DOCX、PDF 导出。
- 成果库与任务中心自动联动缺证据、低置信度、资料过期、同步失败和报告质检事项。
- 统一响应式布局、可调整侧栏、错误/空状态、后台进度与桌面端交互。
- Basic Auth、请求限流、正文大小限制、安全响应头、运维令牌、审计、指标、健康检查和 SQLite 备份恢复。

## RC 加固

- 验证从原始五表数据库升级到当前结构，迁移可重复执行且保留用户数据。
- 导入提交在服务端重新校验，不信任浏览器返回的预览结果；单次导入限制为 5,000 行。
- 畸形 JSON 返回 400，超大 API 请求返回 413，Provider 与模型请求支持实际取消。
- 外部链接仅允许 HTTP/HTTPS，CSV 导出会中和电子表格公式注入。
- 数据库初始化失败会释放连接；公开健康接口不泄露内部错误。
- 备份生成 SHA-256 校验文件，恢复前验证校验和，并保留经完整性检查的回滚副本。

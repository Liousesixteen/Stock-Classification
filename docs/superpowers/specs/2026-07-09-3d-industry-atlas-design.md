# A 股产业链 3D 星图设计

## 目标

为现有 A 股产业链分类工作台增加一套具有鲜明产品辨识度的 3D 产业链星图，并将同一套“产业情报终端”视觉语言扩展到原有三栏研究工作台。

星图用于快速理解产业结构、发现上下游关系和探索公司；三栏工作台继续承担分类编辑、标的管理和公司深度研究。两种模式共享当前分类、当前公司和搜索状态，用户可随时切换，不丢失上下文。

## 核心体验

### 双模式工作区

顶部提供明确的分段切换：

- `研究工作台`：保留当前分类树、标的列表和公司详情三栏布局。
- `产业链星图`：进入全屏 3D 关系探索界面。

首次打开沿用用户上次选择的模式；没有历史记录时进入研究工作台。工作台顶部提供醒目的“进入星图”入口，保证用户能发现新功能，又不让 3D 初始化影响原有首屏速度。

### 3D 星图结构

节点分为三层：

1. 行业根节点，例如“半导体”。
2. 产业环节节点，例如材料、设备、设计、制造和封装测试。
3. 公司节点，按主营业务、重要相关或待核验显示不同颜色和尺寸。

连线表达分类关系，沿线流动的粒子表达可追溯的数据或证据流。节点空间位置由确定性布局生成，同一数据集每次打开保持稳定，避免用户迷失。

### 交互规则

- 拖动旋转视角，滚轮或触控手势缩放。
- 默认开启缓慢自动巡航；用户一旦操作即暂停，可手动恢复。
- 悬停节点时高亮其直接关系，并降低无关节点和连线透明度。
- 点击公司节点时固定选中状态，右侧立即显示本地已有的公司摘要。
- 点击产业环节时聚焦该分支，并在左侧层级导航中同步选中。
- 双击公司节点或点击“进入公司研究详情”切换回研究工作台，并打开同一家公司。
- 提供重置视角和显示全部节点操作。

## 页面构成

### 顶部情报栏

显示产品名称、当前产业链、节点数量、证据数量、资料同步状态，以及模式切换、巡航和重置视角操作。按钮采用图标或图标加短文字，提供清晰的悬停、按下和聚焦反馈。

### 左侧层级导航

显示产业环节及子类数量，用于快速过滤星图。它是分类树的轻量只读映射，不在 3D 模式内承担增删改操作；编辑操作仍回到研究工作台完成。

### 中央 3D 场景

Three.js 场景全幅展示，不放入装饰卡片。背景采用深墨色网格和低对比颗粒纹理，节点使用薄荷绿、青色、琥珀色和红色形成清楚的关系层级，避免单一蓝紫色科技风。

标签只显示根节点、产业环节和当前视野内的重要公司。相机远离时隐藏普通公司标签，靠近或悬停时再显示，控制视觉密度。

### 右侧公司快照

公司快照固定为短模板，确保用户一眼看懂公司：

- 公司名称、代码、市场和所属环节。
- 一句话定位。
- 核心业务及主要业务占比。
- 核心竞争优势。
- 产业相关度、证据数量和资料置信度。
- 进入公司研究详情按钮。

所有字段优先读取本地数据库和缓存。缺失字段显示“资料补全中”或“待补充”，不使用长篇占位说明。

### 底部实时状态条

显示最近同步事件、证据更新或后台补全状态，并提供相机位置等轻量调试信息。正式产品中调试信息默认隐藏，仅在开发模式显示。

## 视觉系统

整体采用“产业情报终端”方向：

- 主背景：近黑墨绿色。
- 主强调色：薄荷绿，用于产业节点、选中状态和主要动作。
- 辅助色：青色用于主营公司，琥珀色用于重要相关，红色用于风险或待核验。
- 标题使用适合中文的宋体或衬线字体，操作和数字使用紧凑的无衬线或等宽字体。
- 卡片边角不超过 8px，面板以细边线、轻透明和适量背景模糊建立层次。
- 动效聚焦节点呼吸、证据粒子流、面板内容切换和模式过渡，不加入无意义装饰动画。

研究工作台同步采用同一套颜色、字体、按钮反馈和状态语言，但保持浅层次高密度布局，不强制变成 3D。

## 组件边界

### `IndustryAtlas`

负责模式级布局、加载状态、节点选择和左右面板编排。它不直接处理 Three.js 对象细节。

### `IndustryGraphScene`

负责 Three.js 场景、相机、灯光、节点、连线、标签、射线拾取和动画循环。通过属性接收标准化图数据，通过回调上报悬停和选中节点。

### `AtlasLayerNav`

负责产业环节过滤和节点数量展示。读取与分类树相同的只读数据模型。

### `AtlasCompanySnapshot`

负责公司短模板和资料补全状态。只消费标准公司研究摘要，不直接调用数据源。

### `WorkbenchModeSwitch`

负责研究工作台和产业链星图之间的切换，并将模式记录到本地存储。

### `industryGraphAdapter`

将现有分类树、公司关系和证据状态转换为稳定的图谱节点与边。为节点生成稳定 ID 和确定性坐标种子，隔离数据库结构与渲染结构。

## 数据流

1. 页面先加载现有分类和关系数据，研究工作台可立即使用。
2. 用户进入星图模式后，动态加载 Three.js 与星图组件。
3. `industryGraphAdapter` 将已有数据转换为图谱数据。
4. 场景首次显示本地已有节点；公司摘要从客户端缓存或现有 API 读取。
5. 后台同步完成后，仅更新对应节点状态和右侧摘要，不重建整个场景。
6. 在任一模式选择分类或公司时，公共工作台状态同步更新。

## 性能要求

- 研究工作台首屏不打包 Three.js，星图代码按模式动态加载。
- 进入星图后 2 秒内显示可交互的基础节点；标签和粒子效果可在随后渐进补齐。
- 桌面端目标为常用数据规模下 50 至 60 FPS。
- 默认同时渲染的公司节点设置上限；超出时按当前分类、关系强度和视距分层显示。
- 页面不可见时暂停动画循环。
- 自动根据设备性能降低像素比、粒子数量、阴影和标签密度。

## 降级与可访问性

- WebGL 不可用时显示二维关系图和公司列表，不出现空白场景。
- `prefers-reduced-motion` 开启时关闭自动巡航、节点呼吸和持续粒子动画。
- 所有关键操作可通过键盘完成；节点提供可读名称，右侧快照承担完整文本信息。
- 移动端不复制桌面三栏。星图全屏展示，分类筛选和公司快照使用底部抽屉。

## 错误处理

- 图谱数据请求失败：保留已缓存图谱，并在状态条提示资料可能不是最新。
- 单个公司摘要失败：节点仍可选中，右侧显示基础资料和重试操作。
- Three.js 初始化失败：自动切换二维降级视图，并保留返回研究工作台入口。
- 后台同步中：使用非阻塞状态提示，不禁用节点选择和模式切换。

## 测试与验收

### 单元测试

- 图谱适配器能稳定生成节点、边、层级、颜色和确定性布局种子。
- 缺失字段能映射为明确状态，不产生长占位文本。
- 模式切换能保留当前分类和公司。

### 组件测试

- 左侧筛选会更新场景可见节点。
- 选择公司会立即更新右侧快照。
- 降级、加载、同步和错误状态均可见且不阻塞基础操作。

### 浏览器验证

- 在桌面和移动视口检查场景非空、构图完整、标签不遮挡主要操作。
- 验证拖动、缩放、巡航、节点高亮、公司选择和返回研究详情流程。
- 使用 Canvas 像素检查确认 3D 画面真实渲染。
- 检查控制台无持续错误，切换页面后动画循环停止。

## 本期范围

本期实现双模式框架、3D 星图、现有数据适配、公司快照、交互联动、响应式降级和视觉系统升级。

本期不实现用户自定义 3D 布局、多人协作、时间轴回放、VR 模式或复杂图算法推荐。这些能力可在图谱数据接口稳定后继续扩展。

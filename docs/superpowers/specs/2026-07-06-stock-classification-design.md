# A 股产业链股票分类工作台设计

日期：2026-07-06

## 背景

本项目要做一个面向 A 股研究的股票分类软件。它不是普通行情页，也不是概念板块列表，而是一个可维护、可追溯的产业链知识库和标的筛选工作台。

第一版以 A 股为市场范围，建立全 A 股行业框架，并把半导体作为第一个深分类样板。半导体分类需要细到产业链环节和具体方向，例如材料下继续拆分光刻材料、硅材料、湿电子化学品、电子特气、CMP 材料、靶材/前驱体、封装材料；光刻胶下继续拆分 g/i 线、KrF、ArF、EUV 等方向。

## 第一版目标

第一版交付一个本地网页应用，让用户可以导入和维护 A 股产业链分类数据，并快速回答：

- 某个细分方向有哪些 A 股公司？
- 哪些公司是真主营，哪些只是相关或概念？
- 每条分类判断的证据来源是什么？
- 哪些分类关系缺证据、低确信度或需要复核？

第一版重点是“分类准确、查找顺手、研究可沉淀”。实时行情、自动荐股、自动交易、多用户协作、云端账号和 AI 自动归类不进入第一版。

## 产品路线

采用“产业链工作台优先”的路线。底层数据按关系模型设计，保留后续升级到知识图谱的空间。

第一版主界面采用三栏工作台：

- 左侧：可折叠产业链分类树。
- 中间：当前细分方向、筛选条件和股票列表。
- 右侧：公司研究详情卡片。

## 主界面设计

左侧分类树支持多层展开和收起。分类节点至少支持行业、一级产业链环节、二级方向、三级细分和更深自定义子类。

半导体材料的首版样板分类包括：

- 光刻材料：光刻胶、g/i 线光刻胶、KrF 光刻胶、ArF 干法/浸没式光刻胶、EUV 光刻胶、显影液、剥离液、抗反射涂层、光掩膜版/掩膜基板。
- 硅材料：6/8/12 英寸硅晶圆片、抛光片、外延片、SOI 硅片。
- 湿电子化学品：高纯酸、碱、溶剂、清洗液、刻蚀液、电镀液。
- 电子特气：刻蚀气体、沉积气体、掺杂气体、清洗气体、载气。
- CMP 材料：CMP 抛光液、CMP 抛光垫、清洗液、调节器。
- 靶材/前驱体：溅射靶材、ALD/CVD 前驱体、MO 源。
- 封装材料：环氧塑封料、基板/载板、键合丝、焊球、底填胶、导热材料。

中间列表显示当前路径，例如“半导体 / 材料 / 光刻材料 / 光刻胶 / ArF 干法与浸没式”。列表字段包括股票代码、公司简称、归类说明、关系类型、确信度和来源。支持按分类路径、公司、关键词、关系类型、确信度、来源类型筛选。

右侧公司详情卡片包含：

- 公司简介：2-4 句话概括主营、核心产品、产业链位置和重点业务线。
- 基础信息：代码、简称、上市板、行业、地区、市值区间、更新时间。
- 分类关系：公司关联到哪些细分方向，每条关系的类型、确信度和判断说明。
- 业务证据：年报、公告、互动易、研报、网页链接、手动摘录等。
- 产品与产业位置：核心产品、上游原料、下游客户/应用、国产替代环节、同类公司差异。
- 研究字段：收入占比、主要客户、产能/项目进度、竞品公司、催化因素、风险点、待验证问题和备注。

## 数据模型

底层采用可升级为知识图谱的关系模型，而不是简单的一张“公司属于某分类”的表。

### 分类节点

分类节点表示产业链中的一个位置或细分方向，例如“半导体”“材料”“光刻材料”“ArF 光刻胶”“12 英寸硅片”。

字段包括：

- 节点 ID
- 名称
- 父节点 ID
- 层级
- 排序
- 别名
- 简介
- 适用行业
- 是否启用
- 创建时间
- 更新时间

分类节点支持新增、编辑、移动、合并和停用。节点可无限层级，但第一版 UI 重点优化 2-5 层的阅读和维护体验。

### 公司

公司表示 A 股上市公司。

字段包括：

- 股票代码
- 公司简称
- 公司全称
- 上市板
- 所属行业
- 地区
- 市值区间
- 公司简介
- 主营摘要
- 最近更新时间

公司基础信息第一版支持自动补齐。系统可以通过内置 A 股基础股票表、用户导入的基础信息表，或后续接入的基础数据源，补齐代码、简称、上市板、行业等字段。自动补齐只处理客观基础字段，不自动判断产业链分类。

### 公司-分类关系

这是最关键的核心表，表示“某公司与某细分方向有什么关系”。

字段包括：

- 关系 ID
- 股票代码
- 分类节点 ID
- 关系类型
- 确信度
- 判断说明
- 主要证据 ID
- 是否待复核
- 创建时间
- 更新时间

关系类型固定为：

- 主营业务
- 重要相关
- 概念/少量布局
- 待验证

确信度固定为：

- 高
- 中
- 低

同一家公司可以关联多个分类节点。每条关系必须能独立说明原因，避免把主营业务、相关业务和蹭概念混在一起。

### 证据来源

证据来源用于支撑分类判断。

字段包括：

- 证据 ID
- 关联关系 ID
- 来源类型
- 来源标题
- 来源日期
- 链接
- 摘录
- 证据可信度
- 是否过期
- 创建时间
- 更新时间

来源类型包括年报、公告、互动易、研报、网页、手动备注和其他。

### 研究笔记

研究笔记可绑定到公司、分类节点或公司-分类关系。

字段包括：

- 笔记 ID
- 绑定对象类型
- 绑定对象 ID
- 笔记类型
- 内容
- 标签
- 创建时间
- 更新时间

笔记类型包括研究备注、催化因素、风险点、争议点、待验证问题、收入占比、客户、产能/项目进度。

## 功能模块

第一版包含 6 个核心模块。

### 产业链工作台

用于日常研究和筛选。左侧选择分类节点，中间查看标的列表，右侧查看公司详情。

### 分类管理

用于维护产业链分类树。支持新增、编辑、移动、合并、停用分类节点。用户可以在半导体之外逐步补其他行业。

### 公司管理

用于维护 A 股公司基础信息、公司简介、主营摘要、行业、上市板和备注。

### 关系管理

用于维护公司与分类节点之间的关系，包括关系类型、确信度、判断说明和待复核状态。

### 证据管理

用于为公司-分类关系添加证据来源。每条证据可以绑定到具体关系，保留来源类型、日期、链接、摘录和证据可信度。

### 数据质量检查

用于发现和处理数据问题，包括缺公司简介、缺证据、低确信度、重复关系、未知分类、待验证关系和可能冲突的关系。

## 导入流程

第一版以 Excel/CSV 导入为主，基础自动补全为辅。

导入流程：

1. 用户选择 Excel 或 CSV 文件。
2. 系统识别股票代码、公司简称、分类路径、关系类型、确信度、来源、判断说明和备注。
3. 系统展示预览结果，标出错误代码、缺失字段、重复关系、未知分类和格式问题。
4. 对未知分类，用户可以选择自动创建新分类或映射到已有分类。
5. 对重复关系，用户可以选择跳过、覆盖或合并证据与备注。
6. 导入后进入待复核列表，优先处理缺证据、低确信度和冲突关系。

基础自动补全规则：

- 如果导入文件只有股票代码，系统尝试补齐公司简称、上市板和行业。
- 如果导入文件提供了公司简介或主营摘要，以用户导入内容为准。
- 如果自动补全结果与导入内容冲突，导入预览中提示用户选择保留导入值或使用补全值。
- 自动补全不改变关系类型、确信度、判断说明和证据来源。

导入模板建议字段：

- 股票代码
- 公司简称
- 分类路径
- 关系类型
- 确信度
- 判断说明
- 来源类型
- 来源标题
- 来源日期
- 来源链接
- 来源摘录
- 公司简介
- 研究备注

## 技术架构

第一版做成本地网页应用。

建议架构：

- 前端：React / Next.js。
- 后端：本地 API 服务。
- 数据库：SQLite 本地文件。
- 导入解析：Excel/CSV 解析。
- 导出：Excel/CSV 导出。

SQLite 适合第一版，因为它本地可靠、部署简单、容易备份。后续如果需要多设备或多人协作，可以迁移到服务端数据库。

## 错误处理和数据质量

导入时必须明确反馈错误，而不是静默失败。

需要处理：

- 股票代码格式错误。
- 必填字段缺失。
- 分类路径不存在。
- 关系类型不在允许范围内。
- 确信度不在允许范围内。
- 同一公司与同一分类重复导入。
- 来源链接为空或格式异常。
- 导入文件字段名不匹配。

系统应提供导入预览和导入结果报告，报告中列出新增、更新、跳过和失败的条目。

## 测试策略

第一版测试重点放在数据正确性和核心工作流。

需要覆盖：

- 分类树展开、折叠、搜索和路径显示。
- 公司-分类关系的创建、编辑、筛选和删除。
- Excel/CSV 导入预览、错误提示和实际导入。
- 未知分类映射和自动创建。
- 数据质量检查结果。
- 公司详情卡片字段展示。
- SQLite 数据持久化。

## 第一版不做

第一版明确不包含：

- 实时行情。
- 自动交易。
- 估值模型。
- 自动荐股。
- 多用户协作。
- 云端账号系统。
- AI 自动归类。
- 自动抓取研报/公告并直接写入分类。

后续可以基于证据结构增加自动辅助能力，但分类判断仍需要人工确认。

## 验收标准

第一版完成时，需要满足：

- 可以在本地启动网页应用。
- 可以看到可折叠的产业链分类树。
- 半导体材料分类达到本设计中的样板深度。
- 可以导入 Excel/CSV 分类数据。
- 可以查看某个分类方向下的相关 A 股公司。
- 可以区分主营业务、重要相关、概念/少量布局和待验证关系。
- 可以为关系添加证据来源和研究备注。
- 可以查看带公司简介的公司详情卡片。
- 可以运行数据质量检查并看到待复核项。
- 数据保存在本地 SQLite 文件中，重启应用后不丢失。

## 后续扩展方向

在第一版稳定后，可以继续扩展：

- 接入外部数据源，自动更新 A 股基础公司信息。
- 接入公告、年报、研报和互动易链接。
- 增加产业链图谱视图。
- 增加产品、客户、供应链、项目进度等实体。
- 增加 AI 辅助摘要和候选归类，但必须经过人工确认后入库。
- 支持桌面应用打包或在线部署。

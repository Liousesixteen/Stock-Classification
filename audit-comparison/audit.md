# 原项目与星图 Demo 综合对比审查

日期：2026-08-19

## 审查范围

- 原项目研究工作台首页
- 原项目产业链图谱全景
- 原项目选中“通富微电”后的公司快照
- Demo 产业链星图全景
- Demo 选中“通富微电”后的上下游关系面板

## 用户目标

保持原项目作为真实研究产品的结构、数据能力和视觉体系，只吸收 Demo 中能明显提升“公司全产业链关系理解”的部分。

## 原项目的真实样式

原项目是“深色产业情报终端”，不是单页视觉 Demo：

- 顶部保留产品身份、研究工作台 / 产业链图谱 / 成果库、任务中心与行情示例。
- 研究工作台采用高密度卡片和三栏研究结构，强调研究进度、证据、成果和任务。
- 产业链图谱采用左侧图层与信号筛选、中间 3D 全景、右侧研究快照、底部视图控制。
- 色彩以近黑海军蓝、哑光金、薄荷绿、青色和少量风险红为主；卡片半径小、边线克制、信息密度高。
- 公司快照已有产业位置、产业相关度、档案质量、有效证据、关系强度、关系与证据链、路径探索及研究动作。

## 原项目应保留

1. 完整产品壳层与双模式结构：研究工作台和产业链图谱必须共存，不能被 Demo 的三项简化导航替代。
2. 3D 星图作为全产业链“全景入口”：它适合展示 56 个分类、71 家公司和跨行业结构。
3. 左侧图层、产业分类、上游/下游/已证实/待复核/缺证据/重点跟踪筛选。
4. 右侧公司研究快照、路径探索、证据节点、档案质量和任务闭环。
5. 真实 SQLite、证据核验、研究任务、AI 研究、报告工坊和成果库能力。
6. 原有 Lucide 图标、Noto Sans SC 字体和“产业情报终端”设计语言。

## Demo 值得吸收

### P1：公司焦点模式的清晰拓扑

点击公司后，不只是在 3D 星系中高亮一个点，而是进入“公司局部产业链视图”：

- 上游供应商 / 设备 / 材料放在上方或左侧。
- 当前公司固定居中。
- 下游客户 / 应用放在下方或右侧。
- 同业竞品放在两侧并使用不同线型。
- 在图上直接显示“供应 / 客户 / 竞争”等方向标签。

建议把它做成原 3D 图谱内的第二级焦点视图，而不是替换原全景图。

### P1：关系详情抽屉

吸收 Demo 的上游 / 下游 / 同业三个页签，但用原项目真实数据驱动。每条关系显示：

- 公司名称与股票代码
- 关系角色与具体品类
- 方向和关系类型
- 关系强度
- 有效证据数、核验状态与最近观察时间
- 进入对方公司关系图的穿透按钮

### P1：关系数量摘要

在原公司快照顶部增加“上游 N / 下游 N / 同业 N”，让用户无需滚动即可判断公司关系完整度。

### P2：公司间连续穿透

从“通富微电 → 北方华创 → 中芯国际”持续查看对方局部产业链，并保留面包屑或返回路径。原项目已有路径探索器，可直接承接该能力。

### P2：局部图与证据抽屉联动

点击关系线或关系卡片时，复用原项目证据节点、有效证据规则、待复核状态和任务中心，而不是仅显示一个模拟证据数字。

## Demo 不应照搬

1. 不使用 Demo 的固定公司名单、固定日期、模拟强度和“均关联公开证据”文案。
2. 不用二维单公司星图替换原 3D 全景；它只适合作为公司焦点层。
3. 不移除原项目的研究工作台、成果库、图层、信号筛选、路径、档案质量和可信边界。
4. 不照搬 Demo 顶部简化导航和底部重复公司摘要；原项目已有更完整的产品导航与右侧快照。
5. 不把大面积说明卡长期覆盖在关系图中央；只保留短提示或在空闲状态展示。
6. 不混用 Phosphor 与 Lucide 图标，也不改变原有金色主操作与薄荷绿证据状态体系。
7. 不宣称供应商、客户和同业关系为事实，除非存在原项目认可的有效证据或明确标记为待复核。

## 数据层缺口

原项目目前擅长：公司 → 产业分类，以及公司 → 产品/技术/客户供应商/项目事件实体。它尚未把“上市公司 → 上市公司”的供应、客户、同业关系作为一级结构统一建模。

建议新增一等公司关系模型：

- source_stock_code
- target_stock_code
- relationship_type（supplier / customer / peer / partner）
- direction
- strength
- rationale
- observed_at
- verification_status / verified_at
- 多条关系证据

不能把 Demo 的公司关系直接硬编码进前端；应先完成这一数据适配，随后同时供 3D 星图、公司焦点图、公司快照、AI 研究和报告引用。

## 推荐合并方案

### 第一阶段：只增强公司焦点体验

1. 保留原全景 3D 星图和左右栏。
2. 选择公司后，中央区域切换为局部清晰关系图。
3. 右侧快照增加上游 / 下游 / 同业标签和关系列表。
4. 卡片完全复用原证据与核验状态。
5. 支持穿透到关联公司并保留路径。

### 第二阶段：补齐数据闭环

1. 新增公司—公司关系与证据表、仓储层和 API。
2. 将现有“客户/供应商”实体中能匹配 A 股公司的记录提升为公司节点。
3. AI 研究与人工录入均写入同一关系模型。
4. 缺证据、待复核、冲突关系自动生成任务。

## 可访问性与体验风险

- 原 3D 图适合全景，但公司关系标签偏小，低视力用户难以快速理解；公司焦点图应提供同步 DOM 列表。
- Demo 的关系页签和卡片阅读性较好，应保留语义按钮、键盘穿透与可见焦点。
- 关系强度不能只靠颜色，必须同时显示数字、方向文本和核验状态。
- 当前原项目数据中“通富微电”有效证据为 0，任何 Demo 式具体供应客户关系都必须标记为样例或待核验，不能直接进入正式产品。

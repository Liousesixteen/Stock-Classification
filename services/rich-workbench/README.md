# Yidianx · 股票与基金工作台

本目录保留市场工作台的完整功能，由主项目的统一启动器托管，并通过同源路径嵌入“市场工作台”。

## 本机启动

在仓库根目录执行：

```bash
npm run dev
```

主启动器会管理本服务的启动、健康检查和退出，不需要单独启动。`python3 server.py` 仅保留给服务级调试；非回环访问仍必须配置 Basic Auth。

## 股票与基金视图

- 默认进入股票视图；当前三只股票来自用户提供的行情截图，仅为观察列表，并非持仓。
- 股票观察台支持输入6位代码手动添加沪、深、北交所股票；系统先用腾讯行情校验名称，新增项保存于本机私有目录，并可单独移除。
- 顶部“股票 / 基金”按钮可随时切换；基金视图保留原有官方净值与披露穿透。
- 开屏总览只展示国内与全球大盘指数，不混入个股或具体 ETF；国内加入中证1000，海外部分覆盖恒生、纳斯达克100、日经225、韩国KOSPI和英国富时100。
- 资金流使用东方财富逐单分类模型：行业显示主力净额及占比，股票分钟序列取最新累计快照，绝不把各分钟累计值再次求和。
- 逐单资金流是成交单大小分类结果，不等于真实机构账户流水。
- 系统性顶部识别使用估值、技术动能、行业宽度和波动率四类已接入证据；情绪换手仍明确标记缺失。覆盖权重不足 70% 或可用维度少于 4 个时不发布综合分数。

## 数据边界

- 行情、净值、估值、资金与新闻均显示来源和数据时点。
- QDII 官方净值可能晚一个交易日；代理行情只用于观察，不推进组合官方结算。
- 缺失数据展示“暂不可用”，不补 0、不伪造。
- `private/`、`rich-state/`、运行缓存、发布快照均与公开源码分离。
- 工作台用于信息整理与条件观察，不构成投资建议，不替用户下单。

## 健康检查

- `/api/health`：进程存活状态。
- `/api/ready`：关键数据是否适合真实访问；硬过期或结构不完整时返回 503。
- `/api/fund-flow`：行业及股票观察列表的逐单资金流、时点、单位、缓存和降级状态。
- `POST /api/watchlist`：添加或移除手动观察股票；请求体为 `{"action":"add|remove","code":"600519"}`。
